# 刷取指南（用户可编辑）

此目录会递归扫描所有 Markdown；新增、修改、删除或重命名后自动热加载，不需要改代码或重启。

每个文件可包含一个或多个一级标题条目，建议一个条目一个短文件：

```markdown
# 核桃
- 关键词：核桃
- 别称：虚空遗物、遗物
- 输出：图片
- 意图：刷取
- 分类：集合刷取指南

正文支持 Markdown 层级与 `{名称图标|可选显示名}`。
```

目录默认值为 `意图：刷取`、`输出：图片`，因此一般无需重复填写。`刷 <关键词/别称>`会先查人工指南，再进入权威核心的具体实体获取查询。人工指南用于集合、效率与经验建议，不替代结构化物品获取事实。
