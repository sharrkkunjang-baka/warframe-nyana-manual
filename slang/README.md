# Warframe 统一黑话内容根

`visual/` 文件夹表示出图回复：其中的黑话文档会渲染成图片发送，而非纯文字。`replies/` 则用于纯文字回复。

`../variables/` 是配卡与黑话共用的公共文段目录，用于集中管理多处重复文本。配卡与支持变量展开的黑话文档（如 `visual/`）可以引用同一份文段，修改一处定义即可统一维护；`replies/` 纯文字回复不执行变量。

此目录由同一个热加载内容系统管理，但分为三种语义，禁止混用：

- `replies/**/*.md`：仅`黑话 xxx`显式前缀返回安全纯文字正文。
- `visual/**/*.md`：仅`黑话 xxx`显式前缀返回富图标图片；裸别称不得抢占动态命令。
- `market/*.md`：WM/买/卖/小店/批量查价使用的稳定市场物品别称。
- `../guides/**/*.md`：`刷 xxx`人工集合/玩法指南，优先于泛称核心查询。
- 根目录 `frames.md`、`mods.md`、`fissure-*.md` 等：既有实体/业务域别称覆盖层，继续兼容。

详细模板见 `replies/README.md` 与 `market/README.md`。旧 `fissures.md` 可继续作为兼容说明文件；没有 `##` 条目时不会报错，也不会阻断配卡。

所有目录只读加载，按内容文件 mtime/size 签名热更新；符号链接会跳过。坏文件会记录文件与行号并仅隔离该文件/域，其他黑话与配卡继续使用；上次有效条目保留。

根目录旧格式：

```markdown
## Orokin Cell
别名：orokin电池、orokin cell
模式：追加
```

“追加”保留系统默认别名，“替换”只使用本条填写的别名。
