# 回复黑话（用户可编辑）

每个 Markdown 可写一个或多个一级标题条目；新增、修改、删除、重命名后，下次查询自动生效，无需重启。

```markdown
# 钢铁中纪
- 关键词：钢铁中纪
- 别称：钢中、中钢、中纪钢铁
- 分类：裂缝

这里写正文。支持普通段落和列表；图片、HTML、链接地址、内容变量和脚本不会执行。
```

兼容字段：`关键词`/`关键字`、`别称`/`别名`，兼容中英文冒号与顿号/逗号。

查询：直接发送关键词或别称；也可发送 `黑话 关键词`。管理命令：`黑话 帮助`、`黑话 列表`。

注意：回复黑话只负责返回正文，不参与 WM 市场物品解析。市场别称请写到相邻的 `market/` 目录。
