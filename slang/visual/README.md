# 可视黑话（用户可编辑）

此目录会递归扫描 Markdown，默认 `意图：黑话`、`输出：图片`。新增条目只需增加 Markdown，无需改 Bot 注册代码。

```markdown
# 开核桃
- 关键词：开核桃
- 别称：开遗物、砸核桃
- 分类：虚空裂缝

正文支持 Markdown 层级与 `{名称图标|可选显示名}`。
```

`输出：图片`会走通用富文档渲染器；普通 `replies/` 默认纯文字且不会执行变量。标题后缀`（生图）`/`（需生图）`仅为兼容写法，加载时会归一化，建议新内容直接使用目录默认值或元数据。

可视黑话正文还支持：

- 单独一行 `{p|相对路径}` 插入图片。路径相对于统一配卡素材根 `source/build-images/`，例如 `{p|武器/沙皇/船员.png}` 对应 `source/build-images/武器/沙皇/船员.png`。
- 单独一行 `{n|分页名}` 强制从该处开始新页面，并使用给定文字作为页面标题。
- `{变量名}` 或带参数的变量调用；变量会在建立 Markdown 标题树之前展开，因此变量正文里的标题、分页和图片标记也会参与渲染。

图片只允许 `png/jpg/jpeg/webp`，并拒绝绝对路径、URL、`..` 越界路径和符号链接。
